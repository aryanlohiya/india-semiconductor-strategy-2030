# Strategic Analysis of India's Semiconductor Manufacturing Ecosystem: Opportunities and Challenges Towards 2030

## Objective

This project analyzes India's semiconductor manufacturing ecosystem from a strategic and business perspective. The study evaluates India's current position in the global semiconductor supply chain, benchmarks major global manufacturers, and proposes recommendations for strengthening India's semiconductor ecosystem by 2030.

## Key Questions

- What is the size of the global semiconductor market?
- What is India's current position in semiconductor manufacturing?
- Which countries dominate semiconductor fabrication?
- What opportunities exist for India?
- What manufacturing strategy should India adopt by 2030?

## Methodology

- Market Research
- Industry Benchmarking
- SWOT Analysis
- Porter's Five Forces
- Market Sizing
- Data Visualization (Python)
- Strategic Recommendations
